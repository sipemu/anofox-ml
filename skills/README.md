# Skills

Claude skills that ship with anofox-ml. Copy a skill directory into
`~/.claude/skills/` (or a project's `.claude/skills/`) to use it.

| Skill | What it does |
|---|---|
| [`anofox-ml-boosting`](anofox-ml-boosting/SKILL.md) | Pick, configure and validate the gradient-boosting estimators (GradientBoosting, HistGradientBoosting, LGBM, CatBoost) in Rust or Python. Covers parity with scikit-learn, LightGBM and CatBoost, and their reproducibility rules. |
